# ATM-system
ATM 自动柜员机模拟系统，基于Java SE实现，课程练手项目。

## 项目介绍
本项目模拟ATM柜员机业务逻辑，实现账户开户、查询、存款、取款、转账、删除账户等功能。
纯Java基础开发，无第三方框架，用于练习面向对象编程。

## 功能列表
- ✅ 开户：新建银行账户，包含账号、用户名、余额
- ✅ 查询：查看账户信息与余额
- ✅ 存款：给账户增加余额
- ✅ 取款：余额校验后扣款
- ✅ 转账：账户之间资金划转
- ✅ 删除账户：注销账户
